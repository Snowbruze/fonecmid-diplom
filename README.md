
# Дипломный проект профессии «1C-программист: с нуля до middle»

## Инструкция по начальной настройке

### Состав релиза

Данные релиз включает в себя новую функциональность и доработку существующих объектов:
- Возможность вести договоры с типом "Абоненское обслуживание";
- Реализована отправка уведомлений о статусах заказов через бота в телеграм-чат;
- Добавлена команда заполнения документа "Реализации товаров и услуг";
- Возможность вести учёт зарплаты, планирования отпусков и премирования сотрудников;
- Добавлено четыре печатных форм для аналитики учёта продаж и расчёта;
- Обработка для массового создания документов "Реализация товаров и услуг".

### Подготовка системы перед эксплуатацией

1. В мессенджере Телеграм создайте групповой чат и чат-бота. Получите идентификатор чата и токен телеграм-бота, которые позже будут введены в систему
2. Заполнение константы "ВКМ_ТокенУправленияТелеграммБотом", "ВКМ_ИдентификаторГруппыДляОповещения", значения которых были получены из пункта 1. При необходимости заполните константы "ВКМ_НоменклатураАбонентскаяПлата", "ВКМ_НоменклатураРаботыСпециалиста" для расширения возможностей при работе с документом "Реализация товаров и услуг". Обязательно заполните константу "ВКМ_НДФЛ".
3. Создайте при необходимости новых пользователей в системе. Установите для них группы доступа, которые определены в группе "Основные профили". В релизе добавлены следующие профили групп доступа:
   - БухгалтерИТФирмы;
   - КадровикРасчетчик;
   - Менеджер;
   - Специалист.
5. Заполните регистр сведений "ВКМ_УсловияОплатыСотрудников", установите значения оклада для всех сотрудников и процент от продаж для специалистов. 
6. Заполните регистр "ВКМ_ГрафикРаботы", его можно заполнить через обработчик "ВКМ_УтверждениеГрафикаРаботы".
